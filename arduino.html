Arduino Measurement System

Development of an electronic temperature measurement system using a thermistor, Wheatstone bridge and Arduino interface.

Objective

The objective of this project was to design and characterize a measurement system capable of acquiring temperature data using electronic components and digital processing.

System Design

The setup included a thermistor sensor, a Wheatstone bridge circuit, an Arduino board and an OLED display for real-time visualization of measurements.

Measurement Process

  • Sensor calibration
  • Signal acquisition
  • Data processing
  • Temperature visualization
