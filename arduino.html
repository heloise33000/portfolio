Arduino Measurement System

Development of an electronic temperature measurement system using a thermistor, a Wheatstone bridge and an Arduino interface.

Project Overview

This project focused on the development of a temperature measurement system based on electronic instrumentation. The objective was to acquire, process and display temperature measurements using a sensor and a microcontroller.

Objectives

  • Design a temperature measurement system
  • Characterize a thermistor sensor
  • Acquire and process measurement data
  • Display real-time results using an OLED screen

Experimental Setup

The system was composed of a thermistor, a Wheatstone bridge, an Arduino board and an OLED display. The electronic circuit allowed the conversion of the sensor signal into a readable temperature value.

Measurement and Data Analysis

The experimental work included sensor calibration, signal acquisition and comparison between measured values and expected theoretical behavior.
